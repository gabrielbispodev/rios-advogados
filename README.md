# Rios Advogados — prévia do novo site

Prévia do redesign do site da **Rios Advogados** (Direito de Trânsito, Goiânia).

- Página estática (HTML, CSS e JavaScript próprios), sem WordPress e sem plugins
- Imagens em WebP no tamanho certo, fontes hospedadas junto do site, carregamento sob demanda
- Animações WebGL ligam só no primeiro gesto do visitante
- SEO e AEO: dados estruturados (LegalService, FAQPage, BlogPosting), `robots.txt`, `sitemap.xml` e `llms.txt`

Publicado com GitHub Pages: https://gabrielbispodev.github.io/rios-advogados/
